## 일치를 확인한 주요 항목

- **API 순서·보안**: 세 API 모두 `crossSiteResponse` → `passwordResponse`(길이 비교 후 `timingSafeEqual`) → 주소 재검사 → `tryAcquire`. 시간 한도 120/100초·60초, 브라우저 1·AI 3, 그림 못 받음·AI 오류는 200 + "확인 필요". `NEXT_PUBLIC_` 0건, 비밀 값은 서버 파일에서만 읽음.
- **AI 판단**: `claude-opus-5-5`, effort `low`, JSON 스키마 구조화 출력, `fallbacks: "default"`, 판정은 코드(`decideVerdict`)가 함.
- **수집**: 1초 간격·60초·2번 재시도, 시간 초과 페이지 1번 더, 본문 그림만, 그림·문장 캡처, 같은 슬라이드 안에서만 바로가기 짝짓기, 홈페이지 경로 ①주소(theme)→②폴더→③문구.
- **엑셀**: 4개 시트 이름·순서, 시트 1의 19열, 그룹ID IMG-/TXT-, 3과정 공통 노란색, 수정 후 빈칸, 캡처 한 번만 넣기, 파일 이름, 다운로드 전 경고.
- **화면**: 3단계 진행률, 처음 3페이지 연속 실패 시 중단, 창 닫기 경고, 비밀번호 칸은 401일 때만.
- **CLAUDE.md 규칙**: 한국어 주석, lib는 상대 경로 + `.ts`, 1판 파일은 trash-can.
