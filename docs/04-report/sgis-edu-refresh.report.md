## 요약 (Executive Summary)

| 관점 | 내용 |
|---|---|
| **문제** | 2027년 SGIS에듀 현행화를 위해, 그림 속 연도가 2026년 이하인 그림과 고칠 문장, SGIS 홈페이지에서 다시 캡처할 경로를 상세 페이지마다 눈으로 찾아야 했다. |
| **해결** | 서버 브라우저가 검색 대상 상세 페이지 40개를 열어 그림·문장·바로가기를 모으고, Claude AI가 그림 속 연도를 읽으면 코드가 2026년 기준으로 판정한다. 결과를 요구사항대로 기록·정렬·병합한 엑셀로 내려받는다. |
| **결과** | 버튼 하나로 약 7~8분, AI 요금 약 1.2~1.3달러. 그림 198개 중 현행화 대상 133개, 수정 필요 문장 약 150개, 무작위 20행 대조 20/20. |
| **핵심 가치** | 놓침 없이 같은 방법으로 매년 다시 돌릴 수 있고, 담당자는 엑셀의 "수정 후" 칸만 채우면 된다. |

## 2. 만든 것

**화면 (app/page.tsx, components/)**
- 시작: 주소 입력·검사, 배포본에서만 실행 비밀번호 칸
- 진행: 대상 찾기 → 페이지 수집 → AI 판단 3단계 진행률, 처음 3페이지 연속 실패 시 중단, 창 닫기 경고
- 결과: 요약 숫자, 실패·확인 필요·경고 목록, [엑셀 다운로드], [다시 검색]

**서버 API (app/api/)**

| API | 하는 일 |
|---|---|
| `POST /api/targets` | 요구사항 표의 3단계 메뉴 아래 상세 페이지 40개(콘텐츠 38 + 스스로하기 2)와 메뉴 위치 약 154곳, SGIS 홈페이지 4개 메뉴의 하위 메뉴를 매번 사이트에서 읽음 |
| `POST /api/refresh-collect` | 상세 페이지 최대 4개를 1초 간격으로 열어 그림·소제목·바로가기·2026년 이하 연도 문장, 그림·문장 캡처, 그림 지문을 모음 |
| `POST /api/judge` | 그림 하나를 Claude Opus 5.5에 보내 연도를 읽고 판정(현행화 대상·대상 아님·연도 없음·확인 필요) |

**엑셀 (lib/excel.ts) — `SGIS에듀_현행화대상_YYYY-MM-DD.xlsx`**
1. 현행화_기록: 대상 그림·수정 필요 문장 × 메뉴 위치마다 한 행, 캡처, 에듀 위치, 최고 연도, 홈페이지 경로, 수정 전·후(후는 빈칸)
2. 현행화_정렬: 같은 그림·문장끼리 정렬, 그룹ID(IMG-/TXT-)
3. 현행화_병합: 그룹 하나를 한 행으로 합침(위치·주소 목록, 나온 곳 수)
4. 수집_기록: 판정 기준, 실패 페이지, 확인 필요·홈페이지 경로 없음·대상 아님·연도 없음 그림 목록

## 4. 주요 결정 (담당자)

| 결정 | 내용 |
|---|---|
| 연도 판단 | Claude AI(Opus 5.5)가 그림을 읽고, 판정은 코드가 함 |
| 홈페이지 경로 | 같은 슬라이드의 "바로가기" 버튼으로. 주소 → 같은 폴더 → 버튼 문구 순서로 맞춤 |
| 수정 후 내용 | 앱은 수정 전만 적고 수정 후는 빈칸 |
| 미래 예측 연도·연도 없는 그림 | 요구사항 문구대로 "대상 아님", 수집_기록 시트에 목록으로 남김 |
| 배포본 보호 | 실행 비밀번호(자동 생성, `.env.deploy`에만 보관) |

## 5. 겪은 문제와 배운 점

| 문제 | 원인 | 해결 |
|---|---|---|
| 넘겨지지 않은 슬라이드의 문장 캡처가 빈 화면 | 복사한 틀에 `slick-slide` 이름표가 남아 숨겨짐 | 슬라이드 이름표를 빼고 복사 |
| 홈페이지 경로 1건 오판 | 통계주제도 하위 6개가 같은 주소, `theme=` 값만 다름 | theme 값 → 하위 이름 순서로 구분 |
| 엑셀 긴 글자 칸이 잘림 | 행 높이를 캡처 높이로만 정함 | 글자 줄 수도 어림해 큰 쪽으로 |
| **배포본에서 40페이지 중 35개 실패** | 서버용 크롬이 꺼질 때 약 1.2GB 문제 기록 파일(core)을 /tmp에 남겨 공간이 가득 참 | 크롬을 켜기 전·끈 뒤에 core 파일 정리, 단계별 기록 추가 |
| 같은 그림을 AI에 두 번 보냄 | 주소 기준으로만 중복을 거름 | 수집 때 지문을 만들어 지문 기준으로 한 번만(Act 1차) |
| 1판 화면을 멈추지 않고 2판을 만들기 | 같은 파일 이름을 쓰면 1판 빌드가 깨짐 | 2판 파일에 `refresh-` 이름을 붙이고, 화면 교체 때 1판을 한꺼번에 trash-can으로 |

- 실제 사이트로 무작위 대조를 해야 숨은 오류(경로 오판)를 찾을 수 있었다.
- PC에서 되는 것이 배포 서버에서도 된다는 보장이 없다. 배포본으로 끝까지 한 번 돌려 봐야 한다.

## 6. 보안·운영

- 비밀 값은 `ANTHROPIC_API_KEY`(AI)와 `RUN_PASSWORD`(배포본 실행 비밀번호) 두 개, 둘 다 서버에서만 읽음. `.env`·`.env.deploy`는 GitHub·Vercel 업로드에서 제외.
- 세 API 모두 다른 사이트 요청 거절(403) → 비밀번호(401) → 주소 재검사 → 동시 실행 제한(브라우저 1·AI 3, 429).
- 결과 엑셀은 내부용. **실제 운영 전에 SGIS에듀 운영 부서에 자동 수집 가능 여부를 확인해야 한다.**
