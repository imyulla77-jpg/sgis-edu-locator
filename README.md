# SGIS에듀 현행화 대상 찾기

[SGIS에듀](https://sgis.mods.go.kr/view/edu/index)를 현행화할 때 필요한 것을 자동으로 찾아 엑셀로 정리해 주는 웹앱입니다.

- 그림 속 최고 연도가 **2026년 이하**인 그림(현행화 대상)
- 그 그림 주변에서 고칠 문장
- 그 그림을 다시 캡처할 **SGIS 홈페이지 경로**

상세 페이지 40개를 하나씩 열어 눈으로 찾던 일을 버튼 하나, 약 8분으로 줄입니다.

## 무엇을 하나요

1. **대상 찾기**: 초등·중학·고교의 검색 대상 메뉴(수업하기·스스로하기·주제보기의 3단계 메뉴) 아래 상세 페이지를 매번 사이트에서 읽어 목록을 만듭니다(2026년 10월 기준 40개). 같은 콘텐츠는 한 번만 열고, 나오는 메뉴 위치는 모두 기록합니다.
2. **수집**: 상세 페이지를 1초 간격으로 하나씩 열어 다음을 모읍니다.
   - 본문 그림과 그 캡처
   - 소제목
   - "SGIS ○○ 바로가기" 버튼
   - 2026년 이하 연도가 들어간 문장과 그 캡처
3. **AI 연도 판단**: Claude AI가 그림에 적힌 연도를 읽고, 코드가 최고 연도로 판정합니다.
   - 2026년 이하면 현행화 대상, 2027년 이상이나 연도가 없으면 대상 아님입니다.
   - AI가 읽지 못하면 "확인 필요"로 두고, 값을 지어내지 않습니다.
   - 내용이 같은 그림은 한 번만 판단합니다.
4. **홈페이지 경로**: 같은 화면(슬라이드)의 바로가기 버튼을 SGIS 홈페이지 메뉴(통계주제도·대화형 통계지도·활용서비스·분석지도)와 맞춰 경로를 적습니다.
5. **엑셀 내보내기** (`SGIS에듀_현행화대상_YYYY-MM-DD.xlsx`)
   1. 현행화_기록: 대상 그림·고칠 문장을 메뉴 위치마다 한 줄씩. "수정 후" 칸은 비워 두고 담당자가 채웁니다.
   2. 현행화_정렬: 같은 그림·문장끼리 모아 정렬하고 묶음 번호(IMG-001, TXT-001 …)를 붙입니다.
   3. 현행화_병합: 같은 그림·문장 하나를 한 줄로 합칩니다.
   4. 수집_기록: 판정 기준, 실패 페이지, 확인 필요·대상 아님·연도 없음 그림 목록이 들어갑니다.

수집하지 않는 것도 있습니다.
- 로그인 화면, 게시판
- 이용자가 올린 콘텐츠
- sgis.mods.go.kr 밖의 사이트

## 기술

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- 페이지 열기·캡처: `playwright-core`
  - PC: 설치된 Edge(없으면 Chrome)
  - Vercel 서버: 서버용 크롬 `@sparticuz/chromium`
- 연도 읽기: Claude API (`@anthropic-ai/sdk`, 모델 `claude-opus-5-5`)
- 엑셀 만들기: `exceljs` (사용자 브라우저 안에서 생성)
- 데이터베이스·로그인 없음. 결과는 브라우저 메모리에만 있습니다.

## 실행 방법 (담당자 PC 기준)

준비할 것:
- Node.js 24 이상
- Microsoft Edge 또는 Google Chrome
- `.env`에 `ANTHROPIC_API_KEY`

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 열고 [검색 시작]을 누릅니다.

- 걸리는 시간은 약 8분이고, AI 사용 요금은 한 번에 약 1~2달러(실측 약 1.2~1.3달러)입니다.
- 개발 서버는 보안을 위해 이 PC 안에서만 열립니다(`127.0.0.1`).
- 그 밖의 명령:
  - `npm run lint`: 코드 검사
  - `npm run build`: 배포용 빌드
  - `npm run refresh:dev`: 화면 없이 전체 실행. `dev-output/`에 결과·엑셀·무작위 20행 대조표를 저장합니다.

## 배포 (Vercel)

https://sgis-edu-locator.vercel.app 에서 PC 설치 없이 쓸 수 있습니다.

- **실행 비밀번호**가 필요합니다. 남이 실행해 AI 요금이 나가는 것을 막기 위해서예요.
  - 비밀번호 값은 담당자 PC의 `.env.deploy`에만 있습니다(저장소에 없음).
- 서버 지역은 SGIS와 가까운 서울(`icn1`)입니다.
- 서버는 한 번에 수집 1개, AI 판단 3개까지만 처리합니다.

## 보안

- 비밀 값은 `ANTHROPIC_API_KEY`와 `RUN_PASSWORD` 두 개이고, 서버에서만 읽습니다.
  - `.env*` 파일은 GitHub와 Vercel 업로드에서 빠집니다.
- 서버 API는 다음 순서로 요청을 막습니다.
  1. 다른 사이트에서 온 요청
  2. 비밀번호가 없거나 틀린 요청
  3. SGIS에듀가 아닌 주소
  4. 동시에 너무 많은 실행
- 결과 엑셀은 **내부용**이라 이 저장소에 올리지 않습니다(`*.xlsx` 제외).
- 실제 운영에 쓰기 전에 SGIS에듀 운영 부서에 자동 수집 가능 여부를 확인해야 합니다.
